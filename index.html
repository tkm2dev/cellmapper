01ตาราง PLMN ผู้ให้บริการไทย (MCC 520)

แก้ไข/เพิ่มได้ตามข้อมูลจริงในพื้นที่ — โค้ดตามใบอนุญาต ไม่ใช่ตามแบรนด์ปัจจุบัน
PLMNMNCผู้ให้บริการ / นิติบุคคลหมายเหตุ
หลังการควบรวม TRUE–DTAC (2566) เป็น True Corporation และ TOT–CAT เป็น NT โค้ด PLMN ยังคงแยกตามใบอนุญาตเดิม จึงพบหลายโค้ดของกลุ่มเดียวกัน

02สูตร & ค่าคงที่ที่ใช้บ่อย

โครงสร้าง CGI = MCC + MNC + LAC + CI
 • 2G/3G: LAC (16-bit) + CI (16-bit)   • 4G: TAC + ECI (28-bit)

PLMN แบบ BCD (swapped nibble)
 25 f0 50 → สลับต่อ byte → 52 0f 05
 MCC = 520 · MNC = 05 (f = filler เมื่อ MNC 2 หลัก)

LAC/CI = แปลง hex → decimal ตรงๆ
 0x2197=8599 · 0x753ED=480237

แยก Cell ID
 • LTE: eNB = ⌊ECI/256⌋ · Sector = ECI mod 256
 • UMTS: RNC = ⌊CI/65536⌋ · CID = CI mod 65536

Timing Advance → ระยะ
 • GSM ≈ 550 m/หน่วย (0–63 → สูงสุด ~35 km)
 • LTE ≈ 78.12 m/หน่วย

เซกเตอร์มาตรฐาน 3 sector azimuth 0°/120°/240° · beam 65°

03Workflow งานสืบสวน (checklist)

1. รับค่า CGI/serving cell จาก trace หรือหมายเรียกข้อมูลผู้ให้บริการ
2. ถอดรหัส PLMN/LAC/CI (แท็บ Decoder) — ระบุ operator + tech
3. ขอพิกัดเสา (site DB ของ operator) → กรอกในแท็บแผนที่ พร้อม azimuth/beam
4. หากมี TA → เปิดวง TA เพื่อจำกัดระยะบนเซกเตอร์
5. นำเข้า CDR → สร้างเส้นทางการเคลื่อนที่ + timeline
6. หลายเซลล์พร้อมกัน → ประเมินตำแหน่ง (triangulation)
7. Export โครงงานเพื่อแนบสำนวน
